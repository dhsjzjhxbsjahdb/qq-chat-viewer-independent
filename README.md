# qq-chat-viewer-independent

QQ-style redacted static chat archive.

## 浏览方式

- 日期导航按时间连续浏览，搜索支持文字、回复和转发内容。
- 同一范围内的事件合并成一个入口，保留重点、情绪、连发等多个标签；各分类都能找到该事件，“下一个事件”在当前分类内前进。
- “高峰”是单日消息量的统计标记，不再用整天范围覆盖当天的其他事件。
- 工作、日常对话按连续交流片段分类，默认只显示一行「折叠了 N 条 · 原因」（日常闲聊 / 工作交接 / 工作交接 · 含魔女2未公开内容）；含魔女2未公开内容的片段不能展开，其余折叠片段之外的魔女2消息显示为一行「已隐去 N 条」，同样不能展开，也不出现在搜索结果中；仅有这两类标签的事件不出现在“全部”事件列表中。点分类查看对应事件，再点事件或聊天区摘要展开原文；点击“收起”可再次折叠。
- 涉及争议、重点事件和现有批注的交流仍可浏览。纸蝶与制作组之间的报价、加价、报酬、奖金及工作争执保留；牵扯第三方主体的商务往来、合作条件和评价显示为 `*******`。自动分类采用保守规则，无法明确分类的内容保留显示。
- 同一段交流中只有事件本身、批注、谈报酬的几句（单独成「报价」事件）和争议相关的几句保留显示，其余部分按工作 / 日常分别折叠；发了文件就算工作交接，紧挨工作交接的短片段跟随归入，同一天首尾相连的同类片段合并。
- 所有遮盖文字统一为 `*******`。魔女2 对话和 2026 年 9 月 14 日整天按「魔女2未公开内容」处理，所在片段折叠且不能展开；第三方商务信息按「商务敏感内容」处理，只把被遮的几句收成「已隐去 N 条」，所在片段仍可展开。两者都不出现在搜索结果中。
- 正常打开页面或恢复阅读位置时，工作、日常默认折叠；搜索结果及消息直达链接可以打开目标片段。

公开数据本身已脱敏，清理确认的收件人姓名和市级以下具体地址，保留省市、聊天别名、日期和普通上下文。商务脱敏以保护第三方主体为边界，双方个人合作金额与说法保留。未公开的魔女2（续作）工作对话共 58 段，文字已在数据中替换为 `*******`，消息编号、时间、发送人、类型和图片 / 文件占位保留。脱敏范围与统计记录在 [privacy-report.json](privacy-report.json)（`supplemental_review`、`sequel_review`）；魔女2 遮盖可用 `node tools/redact-sequel.mjs` 按记录重放，规则见 [sequel-mask.mjs](tools/sequel-mask.mjs)。

2026 年 9 月 14 日的整天讨论（429 条记录）及其他日期中重复引用的原文已替换为 `*******`，包括回复、混合消息和转发正文；2025 年 9 月 14 日不按整天处理。其余商务脱敏只覆盖牵扯第三方主体的投资、发行、捆绑合作、外部项目或画师的合作条件与评价；仅涉及纸蝶和制作组的报价、报酬、结算、奖金及争执已恢复，相关批注与事件摘要也保留。混合消息只遮盖确认涉及第三方的片段，保留同条消息中的个人报酬上下文。原有个人隐私、未公开续作内容和发现的访问凭证仍遮盖；引用、转发中的敏感副本同步处理。范围与字段数见 `sensitive_review`，以其中 `scope_revision` 标记的最新第三方保护规则为准。可运行 `node tools/redact-sensitive.mjs` 重放，规则见 [sensitive-mask.mjs](tools/sensitive-mask.mjs) 和 [public-notes-mask.mjs](tools/public-notes-mask.mjs)。

制作组自身不涉及第三方的财务（如核心成员奖金方案）公开，记录在 `sensitive_review.team_finance_restored`；创始成员童真、此间游不算第三方，与他们相关的内容公开（`sensitive_review.team_members_restored`）；其他成员、前成员的个人情况与金额，以及投资方、发行条款、合作方和外包人员相关内容仍遮盖。

页面用的遮盖区间清单 `masks.js` 由 `node tools/write-masks.mjs` 从 `privacy-report.json` 生成（只含消息编号，标明魔女2 / 商务两类），隐私校验会核对二者一致。

注意：只改写了当前版本，Git 历史中更早的提交仍保留原文。

## 本地运行与校验

静态网页无需构建。在仓库根目录运行以下命令，然后打开终端输出的本地地址：

```sh
python3 -m http.server 8781 --bind 127.0.0.1
```

运行数据保真与事件回归检查：

```sh
node tools/check-privacy.mjs
node tools/check-events.mjs
node --check app.js
```

[check-privacy.mjs](tools/check-privacy.mjs) 还支持 `--baseline-ref <脱敏前的提交>`，在内存中对照原始数据，核对其他字段未变且确认的隐私片段不再出现在公开文本中。校验输出不包含原始隐私信息。

批注编辑器通过 `node tools/annotate.mjs` 启动，仅供本地编辑；静态页面只读取已发布批注。
